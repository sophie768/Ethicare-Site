# Tasmania — destination photography

Licensed photographs for the **Tasmania Destination Guide**.

- **Consumed by:** `site/destinations/Tasmania_Destination_Guide.html` (referenced as `../assets/tas/<file>.jpg`)
- **Naming:** descriptive, kebab-case, `tas-` prefix — e.g. `tas-kunanyi-hobart.jpg`, `tas-salamanca-market.jpg`, `tas-cradle-mountain.jpg`, `tas-bay-of-fires.jpg`.
- **Format:** wide landscape JPG (~16:9), optimised for web. Real Tasmanian scenes only — no stock-posed imagery.

Relocation-guide photo suite lives in `./reloc/`.

## Mislabelled files found in the 5 Aug 2026 library audit

- **`tas-russell-falls.jpg`** — this is **Uluru** (red monolith, outback scrub, Northern Territory),
  not Russell Falls. Was live captioned "Russell Falls" on `tasmania/why.html`, `tasmania/weekends.html`
  and the retired `Tasmania_Relocation_Guide.html`. All three repointed to the genuine
  `tas-the-majestic-russell-falls-in-2686921743.jpg` (verified: ferns, tiered cascade, matches Mount
  Field). Do not use `tas-russell-falls.jpg` for Tasmania; if NT/Darwin work confirms it, it could be
  renamed and reused there.
- **`../hobart/hobart-mona.jpg`** — this is a lit bridge at night (reads as the Tasman Bridge, near-
  identical to `hobart-tasman-bridge.jpg`), not Mona's interior. Was live captioned "Inside Mona" on
  `Hobart_Destination_Guide.html`. Repointed to the genuine
  `tas-hobart-august-18-2024-interior-2533821357.jpg` (verified: excavated sandstone gallery wall,
  matches Mona's real architecture).
- **`tas-hobart-harbour-glow-tasmania-capital-2800386961.jpg`** and
  **`tas-launceston-tamar-valley-glow-map-2770368279.jpg`** (photographs of a printed atlas, found and
  quarantined 4 Aug) were still live on `Hobart_Destination_Guide.html` and the retired
  `Tasmania_Relocation_Guide.html` — the original fix only reached the new `tasmania/` chapter files.
  Both now repointed to genuine photography.

**Still outstanding:** a real Launceston / Tamar Valley photograph (see `glance.html`'s own

## Added 23 Aug 2026

- `tas-hobart-botanical-gardens-autumn.jpg` — deciduous autumn colour over lawns and paths in a
  formal botanical garden: red maple, yellow birch, dressed sandstone walls, clipped hedges, two
  people walking the path, hills beyond. Hobart, on Sophie's attribution. Reads as the Royal
  Tasmanian Botanical Gardens (the sandstone walling and the mature deciduous collection fit), but
  no sign or building identifies it, so **caption it as a Hobart garden in autumn, not by name.**

  Genuinely useful and slightly unusual: it is real deciduous autumn, which almost nowhere else in
  Australia gives you. For a clinician moving from the UK, Ireland or South Africa, "the seasons
  still change here" is a specific and underused argument for Tasmania — and every other Tasmanian
  image in the library is wilderness, coast, or the city. This is the first ordinary, in-town,
  four-seasons photograph in the set.
